# نظام إدارة نشمي كافيه ☕

## متطلبات التشغيل
- Python 3.9+
- pip

## خطوات التشغيل

### 1. تثبيت المكتبات
```bash
pip install -r requirements.txt
```

### 2. تشغيل النظام
```bash
python app.py
```

### 3. فتح المتصفح
- **لوحة الإدارة:** http://localhost:5000/admin
- **منيو الزبائن (QR):** http://localhost:5000/menu

---

## هيكل المشروع
```
nashmi_cafe/
├── app.py              ← الخادم الرئيسي (Flask API)
├── database.py         ← قاعدة البيانات (SQLite)
├── requirements.txt    ← المكتبات المطلوبة
├── nashmi_cafe.db      ← قاعدة البيانات (تُنشأ تلقائياً)
├── templates/
│   ├── admin.html      ← لوحة الإدارة الكاملة
│   └── menu.html       ← منيو الزبائن (QR Code)
└── static/
    └── uploads/items/  ← صور الأصناف
```

## الميزات الكاملة

### نقطة البيع (POS)
- إضافة أصناف للسلة بنقرة واحدة
- دعم الكاش / كليك / الذمة
- تحديد رقم الطاولة واسم الزبون

### إدارة اليوم
- فتح وإغلاق اليوم مع الصندوق الافتتاحي والختامي
- عرض مبيعات اليوم (كاش / كليك / إجمالي)
- سجل الأيام مع إمكانية الحذف
- إغلاق شهري للأرشفة

### الذمم
- إضافة حسابات زبائن بالآجل
- تتبع المديونيات وتسجيل الدفعات
- كشف حساب تفصيلي لكل زبون

### المخزون
- تسجيل الواردات الجديدة
- جرد فعلي مع تعديل تلقائي
- تنبيه عند وصول المواد للحد الأدنى

### إدارة المنيو
- إضافة وتعديل وحذف الأصناف
- رفع صور من الجهاز
- تحكم في التوفر (متاح / غير متاح)

### التقارير
- الأصناف الأكثر مبيعاً والأقل مبيعاً
- تقرير شهري مفصّل
- مقارنة الكاش والكليك

### الإعدادات
- تعديل اسم الكافيه، الهاتف، عدد الطاولات
- بيانات Wi-Fi (تظهر في المنيو)
- كلمة مرور لوحة الإدارة

## منيو الزبائن (QR)

- تصفح الأقسام بسهولة
- عرض الأسعار والصور
- تحديث لحظي من قاعدة البيانات
